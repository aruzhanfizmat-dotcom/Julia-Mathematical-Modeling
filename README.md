# Analysis of Nonlinear Trigonometric Functions using Julia

An academic computing project focused on the numerical analysis, simulation, and automated visualization of nonlinear dynamic equations. This repository demonstrates how abstract mathematical modeling can be transformed into practical computational tools using high-performance scientific programming languages.

## 📌 Project Overview

This project was developed independently as a core computational experiment during my undergraduate studies in Mathematics at Sarsen Amanzholov East Kazakhstan University. 

The primary objective is to investigate the behavior of complex nonlinear systems, specifically focusing on non-monotonic functions such as:
$$y = x + \sin(\pi x)$$

By leveraging the high-performance capabilities of the **Julia language**, the scripts execute efficient numerical computations, generate precise multi-dimensional vector data, and output automated data sheets alongside dynamic visual plots.

## 🚀 Key Features

* **Numerical Computation:** Algorithms built for tracking step-by-step evaluation of nonlinear behavioral patterns.
* **Vector & Matrix Manipulation:** Optimized allocation and manipulation of array structures for multi-frequency datasets.
* **File Input/Output:** Automated pipelines designed to log numerical outputs into structured external data files.
* **Data Visualization:** Clean plotting scripts to visually map and interpret the behavioral limits of the target mathematical models.

## 🛠️ Tech Stack & Environment

* **Language:** Julia (Optimized for scientific and numerical computing)
* **IDE/Environment:** Visual Studio Code (VS Code)
* **Key Packages Used:** 
  * `Plots.jl` (for analytical visualization)
  * `LinearAlgebra.jl` (for matrix and vector operations)

## 📁 Repository Structure

* `src/main.jl` - The primary source code containing algorithm logic and data pipelines.
* `plots/` - Automated graph outputs displaying function characteristics and roots.
* `data/` - Generated computational logs and numerical matrix exports.
